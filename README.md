# 🏓 Unity Pong

A classic Pong game reimagined and built in Unity, now available open-source!

🔗 **Play it now on Itch.io: https://noccio06.itch.io/** 

## 🚀 Features
* Classic arcade gameplay mechanics
* Smooth controls and clean implementation
* Built entirely in Unity with modular C# scripts

## 🛠️ Built With
* **Engine:** Unity
* **Language:** C#

## 📂 Project Structure
* `Assets/` - Contains all scripts, scenes, sprites, and materials.
* `Packages/` - Unity package manager configurations.
* `ProjectSettings/` - Engine and physics settings.
